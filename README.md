# Оселя — Драгобрат

Новий сайт готелю «Оселя» (курорт Драгобрат). Статичний сайт: HTML + CSS + JS, без збірки.
Демо — GitHub Pages; робочий хостинг — Cloudflare Pages + адмінка Decap CMS (після погодження).

## Структура

```
index.html          головна (зима / літо — перемикач на стартовому екрані, ?season=summer)
retreat.html        сторінка «Ретрити»
css/styles.css      стилі
js/main.js          сезон, сніг, номери, меню, галерея, відгуки, бронювання
data/rooms.json     номери: назви, ціни, описи, фото  ← редагуватиметься в адмінці
data/menu.json      меню кухні                         ← редагуватиметься в адмінці
data/reviews.json   відгуки з Google                   ← редагуватиметься в адмінці
assets/img          фото (WebP, дві ширини: 1600 і 800 «-s»)
assets/video        відео стартового екрана й секцій (H.264)
assets/logo         кругла емблема (напис «Оселя» збільшено)
assets/fonts        Kurale (заголовки) і Onest (текст) — SIL OFL
_headers            кешування для Cloudflare Pages
```

## Бронювання

Форма нічого не відправляє на сервер: збирає готове повідомлення (номер / послуга, дати, гості, ім'я)
і відкриває чат рецепції в Telegram або Viber. Текст також копіюється в буфер обміну.
Контакти задаються в `js/main.js` → `CONTACTS`.
